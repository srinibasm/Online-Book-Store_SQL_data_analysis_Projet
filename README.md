# 📚 Online Book Store - SQL Data Analysis Project
## 📌 Project Overview
This project is based on an Online Book Store database using SQL.  
The project demonstrates database creation, table relationships, and data analysis using various SQL queries.

It includes:
- Database creation
- Table creation
- Data retrieval
- Filtering
- Aggregations
- Joins
- Business insights queries

---

## 🛠️ Technologies Used
- PostgreSQL
- SQL

---

## 🗂️ Database Tables

### 1. Books
Contains book details:
- Book ID
- Title
- Author
- Genre
- Published Year
- Price
- Stock

### 2. Customers
Contains customer information:
- Customer ID
- Name
- Email
- Phone
- City
- Country

### 3. Orders
Contains order details:
- Order ID
- Customer ID
- Book ID
- Order Date
- Quantity
- Total Amount

---

## 🔍 Business Questions Solved

### Basic Queries
- Retrieve all Fiction books
- Find books published after 1950
- Show orders placed in November 2023
- Find the most expensive book
- Calculate total revenue
- Find books with lowest stock

### Advanced Queries
- Total books sold by genre
- Average price of Fantasy books
- Customers with multiple orders
- Most frequently ordered book
- Top 3 expensive Fantasy books
- Quantity sold by each author
- Customer spending analysis
- Remaining stock calculation

---

## 📈 Key Insights
- Identified top-selling books and genres
- Calculated total business revenue
- Analyzed customer purchase behavior
- Evaluated stock availability after sales

## 🚀 How to Run the Project

1. Open PostgreSQL / pgAdmin
2. Create a new database
3. Run the SQL script file
4. Execute queries to analyze data
